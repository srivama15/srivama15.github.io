# GoatCounter Analytics

**Dashboard:** https://srivama15.goatcounter.com

## Setup

Added one script tag to `index.html` just before `</head>`:

```html
<script data-goatcounter="https://srivama15.goatcounter.com/count" async src="//gc.zgo.at/count.js"></script>
```

## What it tracks

- Page views per path
- Referrers (where visitors came from)
- Country, browser, OS, screen size
- Unique sessions (estimated)

## Key behaviors

- No cookies — no GDPR banner needed
- Deduplicates refreshes within the same session (~8h window)
- Filters out the site owner if logged into GoatCounter in the same browser
- Use incognito + a different network/device to verify tracking
